# Веб-админка УЦЦП — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** админ делает в браузере всё, что делает в боте (заявки, регистрации, пользователи, справочники) + видит фото/видео заявки; панель открыта на https://uccp.faris.tj.

**Architecture:** общий слой действий в `services/*_ops.py` — проверка прав и статуса, изменение, история, уведомления; вызывают и обработчики бота, и страницы панели. Панель — текущий aiohttp + строки в `views.py`, POST → действие → 303 обратно с flash.

**Tech Stack:** Python 3.12, aiogram 3.32, aiohttp, SQLAlchemy 2 async, SQLite.

**Spec:** `docs/superpowers/specs/2026-11-16-web-admin-design.md`

## Global Constraints

- Без новых зависимостей и шага сборки.
- Панель никогда не меняет модели напрямую — только через функции `services/*_ops.py`.
- Права = свойства `User` (`is_admin`, `can_confirm`, `can_approve_cost`, `can_edit_locked`, `can_manage_users`), как в боте.
- Функции слоя не коммитят (flush), коммитит вызывающий — как `services/flow.py`.
- Отказ — `ops.ActionError(текст для человека)`.
- Действия из панели помечаются в истории «через панель» (contextvar в `history.py`).
- UI/комментарии на русском. Тесты — скрипты `tests/*.py`, запуск `.venv/bin/python tests/<name>.py`; все существующие остаются зелёными.

## Review Focus

1. Действие над заявкой, которую только что закрыли в боте → понятный отказ, без 500 и без изменения.
2. Не-админ (руководитель, сотрудник) шлёт POST напрямую → 403, база не меняется.
3. POST без CSRF-токена или с чужим → 403.
4. Перебор кода входа с подменой `X-Forwarded-For` → блокируется общим лимитом.
5. Медиа чужой заявки по прямой ссылке → 404; файл > 20 МБ → «смотреть в Telegram», без 500.
